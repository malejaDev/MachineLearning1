## Cómo se organiza cada tarea

Dentro de cada carpeta:

- `README.md` dice qué se va a encontrar, de acuerdo con el enunciado.
- `docs/` guarda el documento de la entrega: enunciado, respuestas, interpretaciones y gráficos.
- `src/` guarda el código, en particular el notebook con el que se reproduce el análisis.

El detalle de cada actividad no vive en este archivo. Vive en el README de su carpeta.
