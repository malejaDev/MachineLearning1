## Cómo se organiza cada tarea

- `README.md` dice qué hay en esa carpeta.
- `docs/` guarda el documento de la entrega y las tablas.
- `src/notebook/` guarda el notebook que reproduce el análisis.
- `src/notebook/data/` guarda los datos que el notebook lee desde su carpeta. En la tarea 1 están las caras y el archivo de productos de Amazon.
